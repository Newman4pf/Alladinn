# ALLADINN

Static signal desk. No build step. Open `index.html` on any static host.

Not financial advice. Signals are rules on price, not a promise of profit.

## Put it on GitHub

1. Create a new empty repository on GitHub (no README if you are uploading this folder as-is).
Do not upload `server.cjs` unless you want it. GitHub Pages does not need it.
3. Commit to the `main` branch.
4. In the repo: Settings → Pages → Deploy from branch → `main` → root `/` → Save.
5. Wait a minute. Your site is `https://YOURNAME.github.io/REPO/`.

GitHub Desktop: File → Add local repository → this folder → Publish repository.

## PWA Builder

1. Open [pwabuilder.com](https://www.pwabuilder.com).
2. Paste the GitHub Pages URL (it must be https, not a file on your laptop).
3. Start → Package for Android or Windows.

Icons used: `icon-192.png`, `icon-512.png`. Manifest: `manifest.webmanifest`.
